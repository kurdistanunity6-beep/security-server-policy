1. Overview

Security Server is a Discord bot intended for server safety, moderation, member verification, and administration. Data processing depends on the features actually enabled and configured for a Discord server. This policy covers only Security Server and its operator, not Discord's independent handling of information.

2. Information we may process

  • Discord identifiers: user IDs, server IDs, channel IDs, role IDs, and moderation-related configuration needed for features in use.
  • Membership and security events: joins, verification state, permissions and role changes, and logs of moderation or security actions when enabled.
  • Message information: message content and metadata may be inspected for spam, phishing, prohibited links, or other rule violations only where message-based moderation is enabled and the applicable Discord permissions are available.
  • Verification information: if a web-based verification feature is live, it may process IP addresses, browser/request information, verification outcomes, and risk signals to assess suspicious activity.
  • Service and diagnostic data: error logs and security-event records necessary to troubleshoot or protect the service.

Not every category above is necessarily collected by every server or enabled feature. [CONFIRM WHICH FEATURES AND DATA FLOWS ARE LIVE]

3. Why we process this information

To operate requested moderation and verification functions, assign roles, detect abusive or suspicious behavior, produce audit logs for authorized server staff, respond to support requests, and maintain service reliability. Access to moderation and security logs should be restricted to authorized administrators.

4. Services and sharing

Discord necessarily processes information through its own platform. Where the verification website uses Cloudflare Turnstile, Cloudflare may process request information for abuse detection under its own policies. Hosting providers may process operational logs as part of delivering the service. We do not describe additional recipients here unless they are actually used. [CONFIRM HOSTING AND OTHER PROCESSORS]

5. How long data is retained

Retention periods depend on the implemented database, audit logging, backup, and cleanup behavior. The operator must document actual retention periods, including any security events, Discord identifiers, IP addresses, and backups, before publishing this policy.

6. Your choices and requests

Server administrators may disable certain bot features and remove the bot from their servers. Users may contact the operator to request information about data associated with their Discord account and ask for deletion where applicable. We may need to verify that a requester owns the account before acting on a request. [CONFIRM REQUEST PROCESS]

7. Security

We aim to limit access to data to authorized people and services, use platform permission controls, and avoid collecting data not needed for the enabled feature. No online system can guarantee absolute security. [CONFIRM IMPLEMENTED SECURITY CONTROLS]
